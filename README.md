Deskripsi:
Website ini adalah portofolio pribadi yang menampilkan profil, daftar proyek, riwayat pendidikan, sertifikat, dan kontak. 
Dibangun murni menggunakan HTML, CSS, dan JavaScript (DOM) tanpa framework atau library CSS (seperti Tailwind/Bootstrap), agar ringan dan cepat diakses.

Fitur:
1. Responsive di mobile, tablet, dan desktop
2. Dark/Light mode toggle menggunakan manipulasi DOM
3. Menu untuk navigasi
4. Section: Home, Projects, Education, Certificates, Contact
