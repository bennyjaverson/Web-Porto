## 📝 Deskripsi Singkat
Website ini adalah portofolio pribadi yang menampilkan profil, daftar proyek, riwayat pendidikan, sertifikat, serta informasi kontak.  
Dibangun murni menggunakan **HTML, Plain CSS, dan JavaScript (DOM)** tanpa bantuan framework atau library CSS eksternal (seperti Tailwind atau Bootstrap), sehingga menghasilkan performa yang ringan dan cepat.

---

## ✨ Fitur Utama
* **Fully Responsive:** Menyesuaikan dengan baik di perangkat mobile, tablet, dan desktop.
* **Dark / Light Mode:** Fitur pengubah tema menggunakan manipulasi DOM JavaScript.
* **Interactive Navigation:** Menu navigasi dan tombol interaktif yang responsif.
* **Section Lengkap:** Terdiri dari Home, Projects, Education, Certificates, dan Contact.
